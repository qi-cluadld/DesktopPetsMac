AI 桌宠 · macOS 版   使用说明
==================================================
（这个是 Windows 版桌宠的 Mac 版，十只都在，形象和 Windows 上一样）


一、先装 Python（只需要装一次）
--------------------------------------------------
1. 打开网址：https://www.python.org/downloads/
2. 点黄色的「Download Python 3.x.x」按钮
3. 下载完双击安装包，一路点「继续 / 同意 / 安装」就行
4. 装完不用做任何设置

   （如果你的 Mac 上已经有 Python，这一步可以跳过）


二、运行桌宠
--------------------------------------------------
1. 解压收到的压缩包，会得到一个文件夹 DesktopPetsMac
2. 双击文件夹里的  start.command

   如果弹出「无法打开，因为来自身份不明的开发者」：
       → 在 start.command 上点右键，选「打开」，再点一次「打开」
       （只需要做一次，以后就能直接双击了）

   如果双击后窗口一闪就没了：
       → 打开「终端」(Terminal)，把 start.command 拖进终端窗口，按回车

3. 屏幕上就会出现十只桌宠，它们会自己走来走去


三、怎么操作（Mac 的用法）
--------------------------------------------------
· 两个手指在触控板上点一下       → 弹出菜单
· 按住 Control 键再点一下        → 一样是菜单
· 如果你给 Mac 接了鼠标          → 直接点鼠标右键
· 左键点一下桌宠                 → 戳它一下，它会冒爱心
· 按 Esc                          → 关掉当前这一只（能收到键盘时有效）
· 菜单里「让这只休息（关闭）」   → 关掉这一只
· 菜单里「全部退出」             → 十只一起关掉

   ★ 如果哪只关不掉：用菜单里的「全部退出」最稳；
     还不行就打开「活动监视器」，结束掉名字叫 Python 的进程。


四、你会看到什么 / 正常现象
--------------------------------------------------
· 十只自动出现在屏幕上，各自走动、时不时说一句话
· 两只靠近时会互相打招呼（说「嗨，某某！」）
· 台词是中文的，和 Windows 版是同一份台词表
· 如果宠物窗口是「浅色方块背景」而不是透明——这是正常的，
  说明这台 Mac 不支持透明窗口，程序自动退回了安全样式


五、出问题了怎么反馈
--------------------------------------------------
运行一次之后，桌面上会自动生成一个文件：
      pets-report.txt
把它发回来就行（里面记录了运行信息，出错也有内容）。
